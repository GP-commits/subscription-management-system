# Frontend

Reserved for the independently runnable web client. Keep frontend source, package configuration, tests, and environment examples inside this directory.

Required experiences: authentication and password reset; admin and staff workspace; customer portal; products and variants; plans; quotations and templates; subscription lifecycle; invoices and print view; payments; filtered reports.

The backend remains authoritative for permissions, monetary calculations, status transitions, invoice balances, and recurring billing. Mock data must be clearly identified and must never be mistaken for integrated behavior.

See `../docs/frontend-handoff.md` before implementation.
